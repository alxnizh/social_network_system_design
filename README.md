# [Курс System Design](https://balun.courses/courses/system_design)

## Создание социальной сети для путешественников

### Функциональные требования

- публикация постов с множеством фотографий, описание небольшого размера, геопозиция и/или описание места;
- реакции и комментарии постов других пользователей;
- подписка на других пользователей;
- лента новостей конкретного пользователя;
- лента новостей основанная на подписках в обратном хронологическом порядке;
- список мест с рейтингом популярности и поиск по нему;
- просмотр постов о конкретном месте;

### Нефункциональные требования

Аудитория приложения
- Количество пользователей
  - База будет линейно расти до 10.000.000 DAU через год. Все расчёты производим исходя из этого показателя, если нужна будет нагрузка на дату - можно пересчитать линейно.
- Поведение пользователей
  - 5 запросов в день не в сезон, сезонный коэффициент 4.
  - 75% запросов просмотр, 25% активность, новые посты, реакции.
  - Среднее количество фотографий на пост 4 шт.
  - Средний размер фотографии 500kB.
  - Средний комментарий 500 знаков.
  - Средний пост с фотографиями 2000 знаков.
  - Соотношение постов:
    - 45% - чтение поста
    - 35% - реакция
    - 15% - комментарий
    - 5% - публикация поста
- Регион использования: 
  - Только СНГ.

Особенности приложения
- Сезонность
  - Есть, летние месяцы и новогодние каникулы.
- Хранение данных
  - Всегда.
- Максимальное количество подписчиков:
  - 2.000.000.
- Временные ограничения:
  - Время публикации поста/реакции: не более 3 секунд.
- Доступность приложения
  - Несколько часов простоя в год допустимо.

### Оценка нагрузки

Посты нескольких типов:
- Реакция
  метаданные поста + реакция = 1kB.
- Комментарий
  500 знаков + метаданные поста = 1kB + 1kB = 5kB
- Пост с фотографиями
  4 фотографии x 500kB + метаданные поста + 2000 знаков = 2MB + 1kB + 2kB = 2051kB

Не сезон:

RPS = 10.000.000 * 5 / 86400 = 579 RPS

Посчитаем трафик с учётом доли разных запросов.

Трафик реакций = 579 * 35% * 1kB = 202kB
Трафик комментария = 579 * 15% * 5kB = 434kB
Трафик чтения поста = 579 * 45% * 2051kB = 534115kB
Трафик записи поста = 579 * 5% * 2051kB = 59346kB

Итого:
202 + 434 + 534115 + 59346 = 594097kB

Сезон:

RPS = 579 * 4 = 2315 RPS

Посчитаем трафик с учётом доли разных запросов.

Трафик реакций = 202 * 4 = 810kB
Трафик комментария = 434 * 4 = 1734kB
Трафик чтения поста = 534115 * 4  = 2136458kB
Трафик записи поста = 59346 * 4 = 237384kB

Итого:
594097 * 4 = 2376389kB

Соединений = DAU * 10% = 1000000
